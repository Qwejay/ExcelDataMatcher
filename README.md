# ExcelDataMatcher

ExcelDataMatcher 是一个用于从 Excel 文件中提取特定行数据的应用程序。它使用 Tkinter 和 ttkbootstrap 构建用户界面，并使用 pandas 处理 Excel 文件。

## 功能特点

- **文件兼容**：支持 `.xlsx` 与 `.xls`，可检索单个 Sheet 或跨全表检索，支持指定表头行。
- **高级匹配**：支持`模糊包含`、`精确匹配`与`正则表达式`；支持 `AND/OR` 多条件组合及`指定列`查找。
- **数据清洗**：支持清理单元格内换行符、剔除整行空数据及结果一键去重。
- **流畅体验**：采用多线程后台架构，大文件提取不卡死，自带结果 Treeview 实时预览。
- **结果导出**：提取数据可一键导出为全新 `.xlsx` 文件，并可选择保留来源 Sheet 追踪信息。

* **现代 KPI 指标条**：去除生硬灰底，升级为扁平透气的数据看板（总数/命中/比率）。
* **原生文件拖拽支持**：支持直接将 Excel 文件拖入窗口快速加载。
* **便捷交互**：双击表格单元格一键复制内容；继承原表真实列名作为表头。

### ⚡ 性能与稳定性
* **根除子线程死锁**：解耦 Tkinter 变量跨线程读取，解决后台卡死无响应问题。
* **单次读表与熔断优化**：避免重复解析 Excel，增加百万级虚假空行熔断截断机制，比对速度提升至毫秒级。
* **拖拽闪退修复**：利用消息队列隔离 Win32 钩子与 UI 线程，解决崩溃问题。

### 📊 提取与规则增强
* **按关键词顺序排序**：提取结果默认严格按照用户输入的关键词先后顺序分组排列。
* **黑名单反向排除**：新增 `反向黑名单排除` 开关，支持一键过滤含特定词的脏数据。
* **默认全表检索**：检索范围默认设为全表匹配，并自动联动置灰单个 Sheet 选择框。
* **关键词文件导入**：支持从外部 `.txt` 或 `.csv` 批量载入关键词列表。

### 💾 纯净导出与文件管理
* **纯净 XML 导出**：自动清洗非法低位控制字符，解决 Excel 打开提示“部分内容有问题需要恢复”的报错 [1.1]。
* **原生类型保留**：导出保留数值、日期等原生数据类型，不再暴力转为纯文本。
* **智能自增命名**：导出默认按 `{原文件名}_{动作}_{日期}` 命名，遇同名文件自动追加 ` (1)` 递增尾缀。
* **导出联动**：支持 `.xlsx` / `.csv` 双格式导出，保存后可一键快速打开文件。

### 🖥️ 屏幕与分辨率适配
* **开启高 DPI 感知**：适配 Windows 125%/150% 缩放，告别字体模糊与界面拉扯变形。
* **多分辨率自适应**：按屏幕可视尺寸动态居中启动，完美兼容 1366×768 至 4K 分辨率。

## v1.2 - 2026-8-9

### 新增功能 (Features)
- **多模式匹配**：支持 `包含(模糊)`、`精确匹配`、`正则表达式` 3种匹配模式。
- **逻辑运算符**：支持 `满足任一(OR)` 与 `满足所有(AND)` 逻辑控制。
- **指定列查找**：可限制仅在特定列（如 `A, B` 或 `1, 3`）中查找。
- **数据实时预览**：界面新增 Treeview 表格，提取后直接预览前 100 条数据。
- **溯源标记**：新增“保留来源 Sheet 名称”选项，方便多表合并后追溯数据。

### 性能与体验 (Improvements)
- **多线程架构**：采用后台异步提取，解决大文件处理时界面“未响应”卡死问题。
- **UI 布局重构**：全面改用 Grid 网格布局，解决表头行挤压、遮挡显示不全的问题。

### 鲁棒性与修复 (Fixes)
- **正则安全预检**：非法正则表达式输入时抛出友好的错误提示，防止程序崩溃。
- **文件占用捕获**：导出时如遇到 Excel 文件被占用，自动提示用户关闭后重试。
- **防越界与卡顿**：限制预览表格最大列数，修复部分数据列数不足导致的索引越界。
